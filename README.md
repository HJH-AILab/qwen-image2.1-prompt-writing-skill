# qwen-image2.1-prompt-writing-skill

按官方 Prompt Enhancer（PE）契约**手写** Qwen-Image-2.1 提示词的 skill —— 交付的不是一段话，而是一个**结构**。

## 它是什么

Qwen-Image-2.1 的官方 PE 是两个微调过的 Qwen3.5-VL 9B 改写模型（`t2i` 一支、`edit` 一支，checkpoint 与 system prompt 各自独立、**不可互换**）。本 skill 不运行那两个模型，而是**照它们的契约手写同等产物**：

```
t2i  →  {"rewritten_prompt": "<长英文画面描述>", "wh_ratio": "3:2"}
edit →  {"rewritten_prompt": "<改写指令>", "wh_ratio": "", "ratio_follow": "<image1>"}
```

`wh_ratio` 与 `ratio_follow` **互斥**：一个有值，另一个必须是空串。

**功能边界**：只负责提示词构造，外加「契约在出图链路上怎么兑现」（画幅落地）。出图执行、参数传递、权重与节点接线属部署面。

## 覆盖能力

- **模式判定**：无图 = `t2i`（观察者视角长描述）；有图 = `edit`（操作者视角改写指令）
- **t2i 八步**：拆 brief → 定画幅 → 开篇句 → 前列清单 → 走画面 → 排布文字 → 光照独立成句 → 收尾全景句
- **edit 六条**：语言双决策、属性解耦（泄漏 vs 欠编辑）、锚定/决定、意图分支、图片指代（`<imageN>`）、写作形态
- **透明 RGBA**：模型原生能力，触发词与主体控制实测
- **多人同框比例偏置**：主语位/描述权重杠杆与对策优先级
- **画幅落地**：32 整数倍约束、size 档位与细节预算（512/1024/2048 实测）、编辑档画布跟随 `image_1`
- **参数口径**：`cfg=1` 默认即最优、负向不是删元素器、`negative_prompt` 恒空、`steps=25` 甜点
- **迭代重绘**：同 seed 重绘线性累加变脏的机制与修复配方

## 何时使用

- 用 Qwen-Image-2.1 出图，把大白话扩写成模型能吃的标准描述
- 多图参考编辑（换背景 / 换装 / 合成 / 合影 / 商品组合），需要精确改写指令
- 已有提示词但效果偏（改太猛连带变量、或改太轻看不出变化），按「属性解耦」重排
- 确定输出画幅该给比例还是跟随参考图
- 迭代改图后画面发脏 / 颗粒 / 对比度失调，定位成因与处置

**不适用**：非 Qwen-Image-2.1 模型。Z-Image 走 `zimage-prompt-writing`，H3 视频走 `h3-playbook-skill`。

## 关键实测结论（速查）

- **该写就写满**：词长不构成主要成本（步数与分辨率才是）；模型不会替你猜的（数量、方位、动作形态、材质、配色分区）必须写
- **比例永远是字段，不是描述**：正文绝不写比例/分辨率/像素数
- **画布边长取整到 32 的倍数**，否则被悄悄改写
- **编辑档被编辑的图必须放 `image_1`**——`ratio_follow` 指错槽不报错，只悄悄跟错图
- **身份来自参考图时指向那张图，不要用文字描述五官**——文字描述会让模型重画换人
- **每轮换新 seed、别从上一轮产物接着改**——同 seed 重绘底噪线性累加，第一轮就脏 8 倍
